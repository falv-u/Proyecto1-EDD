Ordena el arreglo de canciones in-situ mediante el algoritmo Insertion Sort iterativo.

Recorre la coleccion desde el segundo elemento (i = 1 hasta n - 1), almacenando la estructura actual en una variable de respaldo (key) y desplazando hacia la derecha aquellos elementos previos que resulten mayores segun el criterio configurado: 0 para cid, 1 para duracion, 2 para anio, 3 para total_rep, 4 para titulo, 5 para artista, 6 para album, y 7 para genero.

Parameters
plPuntero a la playlist cuyo arreglo de canciones sera ordenado en memoria.
criterioCriterio de ordenamiento utilizado para guiar las comparaciones.

Fusiona ordenadamente dos subarreglos contiguos de canciones en O(n).

Reserva memoria dinamica temporal para dos arreglos de canciones auxiliares (subarr_left y subarr_right), copia los elementos de ambas mitades delimitadas por low, med y high, y luego intercala secuencialmente los elementos de menor duracion de regreso en el arreglo original p->canciones, liberando la memoria auxiliar al concluir.

Parameters
pPuntero a la playlist contenedora del arreglo de canciones.
lowIndice de inicio del primer subarreglo.
medIndice intermedio de division entre ambas mitades.
highIndice de finalizacion del segundo subarreglo.
criterioCriterio de ordenamiento utilizado para guiar las comparaciones.

Ordena el arreglo de canciones recursivamente aplicando Merge Sort.

Aplica el paradigma divide y venceras: calcula el punto medio entre los indices low y high, se llama recursivamente para ordenar la mitad izquierda y la mitad derecha por separado, y finalmente combina ambas secuencias mediante la funcion merge().

Parameters

highLimite superior del subarreglo actual.
