Detailed Description

Estructura que contiene todos los datos relevantes de una cancion.

Esta estructura solo contiene dos tipos de datos: para los numeros se usan enteros sin signo con un numero fijo de bytes (8 y 4), y para guardar cadenas de texto se usa un puntero hacia un espacio de memoria asignado por malloc que contenga los datos.
