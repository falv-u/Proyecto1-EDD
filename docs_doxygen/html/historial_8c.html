int agregar_a_historial ( playlist *  h,
const cancion *  c 
)

Inserta una cancion en la ultima posicion del historial.

Verifica si la cancion ya habia sido reproducida previamente; si es asi, la remueve de su ubicacion previa para reubicarla al final. Si el historial ha alcanzado MAX_HISTORIAL elementos, descarta la cancion mas antigua ubicada en la posicion 0 y corre las demas antes de almacenar la nueva cancion en h->cantidad.

Parameters
hPuntero al historial de canciones reproducidas.
cPuntero a la cancion que acaba de ser reproducida.
Returns
Retorna 0 en caso exitoso, 1 si el puntero al historial o la cancion son invalidos.
