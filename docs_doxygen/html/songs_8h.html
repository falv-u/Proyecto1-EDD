Carga las canciones desde un archivo CSV a la playlist. para cierto archivo de ruta, se busca cargar todos sus datos a una playlist, primero se cuentan las lineas que tiene el archivo sabiendo el numero de canciones se reserva la memoria con malloc. se separa el texto segun un separador '|', cada dato separado se guarda en una direccion de memoria en ram, por tanto para no perder el acceso se guarda en un arreglo char *temporal, una vez guardada esa linea, se hace una verificacion sencilla de exito, y si en caso de que en alguna parte de el arreglo temporal apunte a NULL, n<datos_de_cancion en este caso 8, si sucede se salta esa iteracion y esos datos no se guardan en memoria. si caso contrario todo sale bien esos datos son transformados a sus respectivas unidades y se guardan en la playlist.

Returns
Retorna 0 en éxito, 121 si no puede abrir el archivo.
