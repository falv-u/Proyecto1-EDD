Busqueda binaria en version recursiva para localizar una cancion por cid.

Asume que el arreglo pl->canciones se encuentra ordenado ascendentemente por cid. Calcula el punto medio evitando desbordamientos aritmeticos; si el elemento coincide retorna su posicion, de lo contrario se invoca recursivamente sobre la mitad izquierda o derecha segun el valor de cid_buscado respecto al elemento central.

Parameters
plPuntero a la playlist ordenada por identificador.
izqIndice inferior del rango de busqueda.
derIndice superior del rango de busqueda.
cid_buscadoIdentificador numerico exacto que se desea encontrar.
Returns
Indice de la cancion en el arreglo, o -1 si no fue localizada dentro del intervalo.

Centraliza la busqueda de canciones bajo diferentes criterios de seleccion.

Permite ejecutar busquedas segun el parametro de prioridad: 1 para busqueda binaria por ID (requiere orden ascendente de cid), 2 para busqueda por titulo, y 3 para busqueda por artista. Retorna una estructura vacia si no hay coincidencias.

Parameters
plPuntero a la lista de canciones donde se buscara.
prioridadCodigo numerico del criterio (1: cid, 2: titulo, 3: artista).
dato_numericoIdentificador numerico utilizado en caso de prioridad == 1.
dato_textoCadena de texto utilizada para contrastar titulo o artista.
Returns
Estructura cancion con la pista localizada, o estructura inicializada en cero si falla.

Compara dos cadenas de texto ignorando mayusculas y minusculas.

Recorre ambas cadenas de manera secuencial convirtiendo cada caracter a su equivalente en minuscula mediante la funcion tolower(). Finaliza cuando encuentra una discrepancia o cuando se alcanza el terminador nulo en alguna de las cadenas.

Parameters
aPuntero a la primera cadena de caracteres.
bPuntero a la segunda cadena de caracteres.
Returns
Retorna 1 si ambas cadenas son identicas en contenido, 0 si difieren o si alguna apunta a NULL.

Localiza todas las canciones de un artista y guarda sus indices en un arreglo.

Recorre secuencialmente la lista comparando pl->canciones[i].artista con la cadena suministrada. Cuando hay coincidencia, guarda el indice en el arreglo resultados[] siempre que no se sobrepase max_resultados, contabilizando el total encontrado.

Parameters
plPuntero a la estructura con las canciones.
artista_buscadoNombre del artista o conjunto que se desea rastrear.
resultadosArreglo de enteros donde se guardaran los indices de las coincidencias.
max_resultadosLimite maximo de elementos que pueden ser escritos en resultados[].
Returns
Cantidad total de canciones que coincidieron con el artista buscado.
