cancion * ui_toggle_play_pause ( cancion *  actual,
int *  en_pausa,
playlist *  cola,

)

Alterna el estado de reproduccion entre reproducir y pausar.

Play/Pause.

Si no hay cancion activa, toma la primera cancion de la cola y la reproduce. Si ya hay una cancion reproduciendose, alterna entre estado pausado y reanudado.

Parameters
actualPuntero a la cancion en reproduccion actualmente.
en_pausaPuntero a la bandera de estado de pausa (0: reproduciendo, 1: en pausa).
colaPuntero a la cola de reproduccion.
plPuntero al catalogo principal de canciones.
historialPuntero a la lista de historial de reproduccion.
Returns
Puntero a la cancion que queda en reproduccion, o NULL si la cola esta vacia.
